# Changelog

Tutte le modifiche significative al progetto sono documentate in questo file.

Il formato segue [Keep a Changelog](https://keepachangelog.com/it/1.0.0/).
Il versionamento segue [Semantic Versioning](https://semver.org/lang/it/): `MAJOR.MINOR.PATCH`

- **MAJOR**: cambiamento incompatibile con le versioni precedenti
- **MINOR**: nuova funzionalità compatibile con le versioni precedenti
- **PATCH**: correzione di bug compatibile con le versioni precedenti
